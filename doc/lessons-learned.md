\# Lessons Learned



\- Never open two Arduino IDE windows simultaneously — blocks COM port access

\- Always verify sensor model number before writing driver code

\- Breadboards are unreliable for motor circuits — move to PCB early

\- Verify motor direction in open space before competition day

\- Complete calibration before the run clock starts, not during

\- Separate power supplies add complexity — check if Vin range covers it first

\- Loose wiring causes more issues than bad code — solder everything properly

\- Always carry spare sensors and motor drivers to competition

\- Fix all known bugs before competition day, never rely on fixing mid-event
