\# Pin Mapping



\## Arduino Nano Every



| Pin | Connected To | Purpose |

|-----|-------------|---------|

| Vin | +12V Supply | Power input |

| A0 | QTR-8A Sensor 8 | Line sensor (rightmost) |

| A1 | QTR-8A Sensor 7 | Line sensor |

| A2 | QTR-8A Sensor 6 | Line sensor |

| A3 | QTR-8A Sensor 5 | Line sensor |

| A4 | QTR-8A Sensor 4 | Line sensor |

| A5 | QTR-8A Sensor 3 | Line sensor |

| A6 | QTR-8A Sensor 2 | Line sensor |

| A7 | QTR-8A Sensor 1 | Line sensor (leftmost) |

| D3  | TB6612FNG PWMB | Left motor speed |

| D5  | TB6612FNG BIN1 | Left motor direction 1 |

| D6  | TB6612FNG BIN2 | Left motor direction 2 |

| D9  | TB6612FNG AIN2 | Right motor direction 2 |

| D10 | TB6612FNG AIN1 | Right motor direction 1 |

| D11 | TB6612FNG PWMA | Right motor speed |

| D13 | LED | Status indicator |

| GND | Common ground | Ground |
